# Vision models

One folder per model. Run every lesson from the project root, e.g.
`uv run python face/lessons/01_detect_faces.py face/data/samples/lena.jpg`.

| Folder | Model | Status |
|---|---|---|
| `plate/` | Plate reading (ANPR) | done |
| `face/` | Face detection and recognition | in progress |

Inside each model folder:

- `lessons/` numbered step-by-step scripts (in git)
- `configs/` training configs (in git)
- `reports/` or `notes/` results and what we learned (in git)
- `data/`, `runs/`, `output/`, `models/` datasets, training runs, outputs, weights (not in git)
